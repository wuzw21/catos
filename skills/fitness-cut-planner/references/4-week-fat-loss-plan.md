# 4 周减脂保肌训练计划

## 适用前提

这是一份默认示例，适合下面这类情况：

- 有基础力量训练经验
- 目标是在 `4` 周内减重 `1.5` 到 `3.0 kg`
- 不希望明显掉肌肉
- 不希望力量和运动表现明显下滑
- 每周可安排 `4` 次力量训练
- 还能额外安排 `1` 到 `2` 次轻有氧或球类活动

如果没有更多个人信息，可以先按仓库里的默认示例基线执行：

- 男
- `23` 岁
- `80 kg`
- 体脂约 `20%`
- 有力量训练基础

## 核心原则

### 训练

- 保留大重量复合动作，不做纯泵感式减脂计划。
- 每周 `4` 次力量训练，优先保住卧推、深蹲、硬拉或其变式、划船、引体、肩推。
- 每周 `2` 次低强度有氧或高步数，而不是每天乱加 cardio。
- 如果一周里已经有高强度羽毛球或其他爆发类运动，就不要再堆很多 HIIT。

### 饮食

- 维持中等热量赤字。
- 蛋白质足够高。
- 训练日前后给足碳水，保护输出和恢复。
- 脂肪不要压太低。

### 恢复

- 睡眠至少 `7` 小时，优先争取 `7.5` 到 `8.5` 小时。
- 每天步数稳定在 `8000` 到 `12000`。
- 连续两天明显疲劳时，先减 cardio 或训练量，不先硬扛。

## 每周结构

建议按下面的周结构执行：

| 星期 | 内容 | 目标 |
| --- | --- | --- |
| 周一 | 下肢力量 + 短时低强度有氧 | 保持下肢力量 |
| 周二 | 上肢力量 | 保持推拉表现 |
| 周三 | Zone 2 有氧 / 轻打球 / 步行恢复 | 控疲劳、拉高消耗 |
| 周四 | 下肢后链 + 爆发 | 保持速度、髋伸和后链 |
| 周五 | 上肢增肌 + 小剂量间歇 | 保持上肢肌肉量 |
| 周六 | 羽毛球 / 户外活动 / 长步行 | 保持运动表现与活动量 |
| 周日 | 休息 + 拉伸 + 轻步行 | 恢复 |

如果周六已经是高强度运动日，周五的小剂量间歇可以直接删掉。

## 训练日模板

### 周一：下肢力量

1. 深蹲 `4 x 4-6`，`RPE 7-8`
2. 罗马尼亚硬拉 `3 x 6-8`
3. 保加利亚分腿蹲 `3 x 8-10`
4. 腿弯举 `3 x 10-12`
5. 提踵 `3 x 12-15`
6. 平板支撑或悬垂举腿 `3` 组
7. 训练后低强度单车或快走 `15-20` 分钟

### 周二：上肢力量

1. 卧推 `4 x 4-6`，`RPE 7-8`
2. 负重引体或高位下拉 `4 x 6-8`
3. 站姿肩推 `3 x 5-8`
4. 杠铃划船或器械划船 `3 x 6-8`
5. 上斜哑铃卧推 `2-3 x 8-10`
6. 侧平举 `3 x 12-15`
7. 二头弯举 + 三头下压，各 `2-3 x 10-12`

### 周三：恢复有氧

二选一：

- `30-45` 分钟 Zone 2 单车 / 跑步机坡走 / 椭圆机
- `45-90` 分钟轻松羽毛球、散步或户外活动

附加：

- 髋、胸椎、肩关节灵活性 `10-15` 分钟

### 周四：下肢后链 + 爆发

1. 硬拉或陷阱杠硬拉 `3 x 3-5`，`RPE 7-8`
2. 箱跳或壶铃摆动 `3 x 5-8`
3. 前蹲或哈克深蹲 `3 x 6-8`
4. 臀推 `3 x 8-10`
5. 行进弓步 `2-3 x 10` 每侧
6. 腘绳肌弯举 `2-3 x 10-12`
7. 核心抗旋转训练 `3` 组

### 周五：上肢增肌 + 小剂量间歇

1. 上斜卧推或双杠臂屈伸 `3 x 6-10`
2. 坐姿划船 `3 x 8-12`
3. 哑铃肩推 `3 x 8-10`
4. 高位下拉或引体 `3 x 8-10`
5. 胸飞鸟 `2 x 12-15`
6. 侧平举 `3 x 12-20`
7. 二头弯举 + 三头臂屈伸，各 `3 x 10-15`

可选间歇：

- 风阻单车 `6-8` 轮
- 每轮冲刺 `15-20` 秒
- 轮间轻松骑 `80-100` 秒

如果周六有高强度球类，这段直接不做。

### 周六：运动表现日

优先级：

1. 羽毛球或其他专项运动 `60-120` 分钟
2. 没有专项时，做 `45-60` 分钟轻松有氧 + 长步行

目标：

- 保持速度、协调和专项体能
- 但不要打到第二天完全散架

### 周日：恢复

- 轻松步行 `30-60` 分钟
- 拉伸或泡沫轴 `10-20` 分钟
- 不安排高疲劳训练

## 4 周推进

### 第 1 周

- 所有动作先按区间下限做。
- 目标是找到当前切脂期还能稳定输出的重量。
- 不追求练废，保留 `1-3` 次余力。

### 第 2 周

- 主项每个动作加 `2.5` 到 `5 kg`，或每组多 `1` 次。
- 辅助动作总量可比第 1 周多 `1-2` 组。
- 步数和饮食稳定，不要这周暴吃。

### 第 3 周

- 这是最重的一周，但不是拼极限的一周。
- 主项维持 `RPE 8` 左右即可。
- 如果感觉恢复很好，可在主项最后一组做一次接近上限的高质量组。

### 第 4 周

- 总组数下降 `30%` 到 `40%`。
- 主项重量保持到第 3 周的 `85%` 到 `90%` 左右。
- 有氧保留，但时间略减。
- 目标是减脂继续推进，同时把疲劳压下来。

## 饮食目标

如果没有更精确的个体数据，可以先用仓库默认工作区间：

- 训练日：`2300-2500 kcal`
- 恢复日：`2100-2300 kcal`
- 蛋白质：`160-180 g / 天`
- 脂肪：`55-70 g / 天`
- 碳水：剩余热量补足，训练日更高

更简单的执行法：

- 每餐先保证一份高蛋白主菜
- 训练前 `1-2` 小时吃主食 + 蛋白质
- 训练后优先补蛋白质和碳水
- 外食时先控油和酱，再控份量

## 表现保护规则

- 主项力量如果连续 `2` 次训练都明显下降，先检查睡眠和饮食。
- 如果专项运动感觉腿很沉，先删掉周五间歇，不要删主项力量。
- 如果晨间心率持续升高、食欲很差、训练发空，热量先加回 `100-150 kcal`。
- 如果体重两周都不动，再减 `100-150 kcal` 或每天多加 `2000` 步。

## 每周检查

每周至少看这 `5` 件事：

1. 周平均体重是否下降
2. 卧推、深蹲、硬拉或主要动作是否基本稳住
3. 羽毛球或其他专项时的脚步和爆发是否还在线
4. 睡眠是否稳定
5. 饮食是否真的达到了蛋白质目标

## 计划成功标准

4 周后，下面三条里满足两条以上，就算这轮计划有效：

- 体重下降 `1.5` 到 `3.0 kg`
- 主项力量仅小幅波动，未明显崩掉
- 羽毛球或其他运动表现基本保持

## 日志记录格式

训练记录尽量兼容仓库现有 `train:` 协议，例如：

```text
train: 下肢力量 75 分钟，深蹲 100kg 4x5，RDL 80kg 3x8，分腿蹲 3x10，训练后快走 15 分钟
```
